# Keep Cleaning

Keep Cleaning is a simple browser game where you clean colorful blocks
by clicking your mouse over them or dragging your finger across the screen.
Clear all 5 blocks to complete a round and the supportive message will appeared after you finish each round.

## 🎮 Play the Game
[Play Keep Cleaning](https://ngohchatchanun.github.io/keep-cleaning/)

## 📚 What I Learned
This project started as my final project for Stanford Code in Place.
While turning it into a web game, I learned about:
- Translating a Python game concept into JavaScript
- Working with HTML Canvas
- Handling mouse and touch interactions
- Working with screen and canvas coordinates
- Generating random positions
- Preventing overlapping objects
- Making a game responsive for mobile devices
- Using GitHub and GitHub Pages to publish a web application
